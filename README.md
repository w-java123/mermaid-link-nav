# Mermaid Link Navigator（Obsidian 插件）

在 Mermaid 流程图的**节点里直接写 `[[笔记链接]]`**，阅读模式下点击节点即可跳转到对应笔记，效果类似 MermaidMaker，但只聚焦「渲染 + 节点跳转」这一件事。

## 功能

- **笔记大纲一键变标准 Mermaid 流程图**：命令面板执行「Mermaid Link Navigator：打开当前笔记的流程图视图（Mermaid）」，自动读取当前笔记的标题（`#`~`######`）与列表（`-/*/+`，按缩进）层级生成 flowchart；根节点为笔记名，标题为方框、列表项为圆角框；编辑笔记后自动刷新
  - **Ctrl/⌘+鼠标左键单击节点查看详情**：定位跳转到笔记对应行（`Alt+单击`分屏、中键新标签、右键菜单选打开方式；普通单击不跳转）
  - **双击节点放大视野并展开其子节点**（整棵子树展开、保留上游路径）；**再次双击（或双击空白/`Esc`/返回全图）缩小视野并收起子节点**，回到只显示根与第一层的折叠总览
  - 工具栏可切换纵向/横向流程、展开全部/收起子树、刷新
- 正常渲染 Mermaid 流程图 / 时序图等全部 Mermaid 图形（内置 Mermaid 11，不依赖网络）
- 节点标签中支持 `[[笔记]]`、`[[文件夹/笔记]]`、`[[笔记#标题]]`、`[[笔记|显示别名]]`、`[[#本笔记标题]]`
- **双击节点聚焦放大**（对标 Better Mind Map）：大图里双击任意节点，自动隐藏无关分支并平滑放大到该节点及其下游（默认保留上游路径）；再次双击该节点、双击空白处或按 `Esc` 恢复全图
- 点击节点 = 点击 Obsidian 内部链接（**需按住 Ctrl/⌘ 才跳转，普通左键单击不跳转**）：
  - `Ctrl/⌘ + 单击`：按设置在当前标签页 / 新标签页 / 分屏打开目标笔记
  - `Alt + 单击`：始终分屏打开
  - 鼠标中键、键盘 Tab 聚焦后回车也可打开
- **双击节点放大视野并展开其子节点**，再次双击（或双击空白 / `Esc` / 「收起子树」按钮）缩小视野并收起子节点，回到只显示根与第一层的折叠总览
- 目标笔记不存在时，节点边框显示为虚线（等同未解析链接），点击会按 Obsidian 规则新建笔记
- 悬停高亮可点击节点，并显示目标笔记路径提示
- 主题自动跟随 Obsidian 明暗模式，可在设置中固定
- 兼容桌面端与移动端

## 安装

1. 把整个 `mermaid-link-nav` 文件夹复制到你仓库的 `.obsidian/plugins/` 目录下（文件夹内需要有 `main.js`、`manifest.json`、`styles.css`）。
2. 在 Obsidian「设置 → 第三方插件」中关闭安全模式，找到 **Mermaid Link Navigator** 并启用。

> `main.js` 已构建好，可直接使用。想自行构建：在本目录执行 `npm install`，再执行 `npm run build`。

## 用法

### 推荐写法（节点标签用双引号包起来）

因为链接里含有 `#`、`|` 等符号，建议始终用双引号包裹标签：

````text
```mermaid
flowchart LR
  A["[[首页|🏠 首页]]"] --> B(["[[项目总览]]"])
  B --> C{{"[[架构设计#数据库模块|数据库设计]]"}}
  B --> D["[[部署手册]]"]
```
````

渲染后：

- A 显示「🏠 首页」，点击打开《首页》
- B 显示「项目总览」，点击打开《项目总览》
- C 显示「数据库设计」，点击跳转到《架构设计》的「数据库模块」标题
- D 显示「部署手册」

### 简单写法（无 `#`、`|` 时可省略引号）

````text
```mermaid
flowchart TD
  A([[首页]]) --> B[[会议纪要]]
```
````

### 支持的节点形状

矩形 `[]`、圆角 `()`、圆形 `(())`、菱形 `{}`、六边形 `{{}}`、圆柱 `[()]`、子程序 `[[]]`、旗帜 `>]`、平行四边形 `[/ /]` 等全部 flowchart 节点形状均可。

### 不想接管原生 mermaid？

默认情况下本插件会接管所有 ```` ```mermaid ```` 代码块（没有链接的图渲染效果与原生一致）。
如果想保留 Obsidian 原生渲染，可以：

- 在设置中关闭「接管原生 mermaid 代码块」，把需要跳转的图改用 ```` ```mermaid-link ```` 代码块；
- 也可以在设置里添加额外语言别名（如 `mmd`）。

## 设置项

| 设置 | 说明 |
| --- | --- |
| 接管原生 mermaid 代码块 | 普通 mermaid 块是否由本插件渲染，改后需重新加载插件 |
| 额外生效的代码块语言 | 逗号分隔的别名，如 `mmd` |
| 图表主题 | 自动 / 浅色 / 深色 / forest / neutral |
| 默认打开方式 | 当前标签页 / 新标签页 / 左右分屏（修饰键优先级更高） |
| 双击节点聚焦分支 | 总开关，关闭后只剩单击跳转 |
| 聚焦时保留上游路径 | 关闭后只显示下游，不显示祖先链 |
| 单击/双击判定延时 | 默认 220ms，防止双击时误触发跳转 |
| 聚焦动画时长 | viewBox 缩放动画毫秒数，0 为无动画 |
| 聚焦留白比例 | 聚焦后节点四周的留白大小 |
| 悬停提示 | 鼠标悬停节点时显示目标笔记 |
| 悬停高亮 | 高亮可点击节点 |

命令面板中还提供「重新渲染当前笔记中的 Mermaid 链接图」命令，切换主题后可手动刷新。

## 注意事项

- 链接写在**节点**上才会绑定点击；写在连线标签（`-->|文字|`）上只会显示别名，不可点击。
- 一个节点里写多个链接时，第一个链接作为跳转目标，其余仅替换为显示文本。
- 本插件不提供图形编辑能力（拖拽改图），需要可视化编辑可配合 MermaidMaker 使用。

## 目录结构

```text
mermaid-link-nav/
├── manifest.json        插件清单
├── main.js              构建产物（直接安装用）
├── styles.css           样式
├── src/
│   ├── main.ts          插件主逻辑：代码块渲染、跳转、双击聚焦、设置页
│   ├── outline.ts       笔记大纲树解析 + 大纲转 mermaid flowchart（纯函数）
│   ├── outline-view.ts  「笔记流程图」ItemView：mermaid 渲染 + 单击跳行 + 双击聚焦
│   ├── parser.ts        mermaid 源码解析：节点 wikilink 与连线关系提取
│   ├── focus.ts         聚焦图算法（祖先链 + 后代子集，纯函数）
│   ├── focus-dom.ts     SVG 显隐与 viewBox 缩放动画控制器
│   ├── node-id.ts       从渲染后 DOM 还原源码节点 id
│   └── *.test.ts        单元 / 端到端测试
├── esbuild.config.mjs   构建脚本
├── tsconfig.json
└── package.json
```
